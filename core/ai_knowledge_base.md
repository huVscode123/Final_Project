## SYN Flood 攻擊
[tags: syn flood, syn攻擊, 洪水攻擊, tcp攻擊, ddos, 半開連線]

### 什麼是 SYN Flood？
SYN Flood 是一種常見的 DDoS（分散式阻斷服務）攻擊手法。攻擊者會大量發送 TCP 連線請求（SYN 封包）給目標伺服器，但故意不完成三向交握（three-way handshake），導致伺服器累積大量「半開連線」，最終耗盡資源而無法回應正常用戶。

### 怎麼判斷遭受 SYN Flood？
- 短時間內出現大量來自不同 IP 的 SYN 封包
- 伺服器連線數異常暴增
- 在 VNAAP 平台上，會在告警清單中看到 `syn_flood` 類型的告警

### 如何防禦？
- 啟用 **SYN Cookies**：讓伺服器不需要為每個 SYN 封包預留記憶體
- 設定防火牆的 **連線速率限制**（Rate Limiting）
- 使用 **CDN 或雲端 DDoS 防護服務**（如 Cloudflare、AWS Shield）
- 調高作業系統的 TCP 佇列（backlog）容量

## ARP 欺騙（ARP Spoofing）
[tags: arp spoofing, arp欺騙, arp攻擊, 中間人攻擊, mitm, 區域網路攻擊]

### 什麼是 ARP 欺騙？
ARP 欺騙是一種在區域網路（LAN）中的攻擊手法。攻擊者會發送偽造的 ARP 回應封包，讓區域網路中的其他電腦誤以為攻擊者的 MAC 位址就是網路閘道的 MAC 位址，於是所有對外流量都會先經過攻擊者的電腦，形成「中間人攻擊」（Man-in-the-Middle）。

### 有什麼危害？
- 攻擊者可以**竊聽**所有未加密的網路流量（帳號密碼、聊天內容等）
- 攻擊者可以**篡改**傳輸中的資料
- 攻擊者可以**阻斷**網路連線

### 如何防禦？
- 使用 **靜態 ARP 表**（適合小型網路）
- 啟用交換器的 **Dynamic ARP Inspection（DAI）**
- 確保重要連線都使用 **HTTPS / TLS 加密**
- 使用 VPN 來保護敏感通訊

## Port Scanning（通訊埠掃描）
[tags: port scan, 通訊埠掃描, 埠掃描, nmap, 偵查攻擊, 資訊收集]

### 什麼是 Port Scanning？
Port Scanning 是攻擊者用來「探測」目標電腦上有哪些服務正在運行的偵查手法。就像小偷在闖入前先繞房子一圈，試試每扇門窗是否有開。攻擊者會逐一嘗試連接目標的各個通訊埠（port），看哪些有回應。

### 常見的掃描方式
- **TCP Connect Scan**：完整的三向交握，最明顯也最容易被偵測
- **SYN Scan（半開掃描）**：只送 SYN，不完成交握，較隱蔽
- **UDP Scan**：掃描 UDP 通訊埠，速度較慢

### 如何防禦？
- 用防火牆**關閉不需要的通訊埠**
- 啟用 **入侵偵測系統（IDS）** 監控異常掃描行為
- 定期檢查伺服器上運行的服務，關閉不必要的服務

## DDoS 攻擊（分散式阻斷服務）
[tags: ddos, 分散式阻斷服務, 阻斷攻擊, dos, 流量攻擊, 殭屍網路]

### 什麼是 DDoS？
DDoS（Distributed Denial of Service）是指攻擊者利用大量被感染的電腦（殭屍網路/Botnet）同時向目標發送海量請求，讓目標伺服器因為處理不過來而癱瘓，正常用戶就無法使用該服務。

### DDoS 的種類
- **流量型（Volumetric）**：用超大流量塞爆頻寬（如 DNS Amplification、NTP Reflection）
- **協定型（Protocol）**：消耗伺服器資源（如 SYN Flood、Ping of Death）
- **應用層型（Application Layer）**：針對特定服務發送看似正常的大量請求（如 HTTP Flood）

### 如何防禦？
- 使用 **雲端 DDoS 防護服務**
- 設定**流量清洗（Scrubbing）**機制
- 建立**冗餘架構**，分散流量負載
- 與 ISP 合作，在上游過濾異常流量

## DNS Amplification 攻擊
[tags: dns amplification, dns放大攻擊, dns攻擊, 反射攻擊, udp攻擊]

### 什麼是 DNS Amplification？
DNS Amplification 是一種利用 DNS 伺服器的「放大效應」來發動 DDoS 攻擊的手法。攻擊者偽造受害者的 IP 位址，向大量 DNS 伺服器發送查詢請求。由於 DNS 回應的資料量遠大於查詢的資料量（放大倍率可達 50 倍以上），受害者就會收到海量的 DNS 回應，頻寬被塞爆。

### 如何防禦？
- DNS 伺服器管理者應**關閉遞迴查詢**（Open Resolver）
- 網路管理員應實施 **BCP38 / 來源 IP 驗證**，防止 IP 偽造
- 使用流量清洗服務過濾異常的 DNS 回應

## 惡意軟體（Malware）
[tags: malware, 惡意軟體, 病毒, 木馬, 蠕蟲, 勒索軟體, ransomware, 後門]

### 什麼是惡意軟體？
惡意軟體是任何被設計來損害電腦系統、竊取資料或未經授權取得存取權限的軟體。

### 常見類型
- **病毒（Virus）**：附著在正常程式上，需要使用者執行才會啟動
- **蠕蟲（Worm）**：可以自我複製並透過網路自動傳播
- **木馬（Trojan）**：偽裝成正常軟體，實際上暗藏惡意功能
- **勒索軟體（Ransomware）**：加密你的檔案，要求付贖金才解鎖
- **後門（Backdoor）**：在系統中開一個秘密入口，讓攻擊者隨時回來

### 如何防禦？
- 安裝並**定期更新**防毒軟體
- **不要隨意下載**來路不明的軟體或附件
- 保持作業系統和軟體的**安全更新**
- 重要資料**定期備份**（3-2-1 原則）

## 網路封包是什麼？
[tags: 封包, packet, 網路封包, 什麼是封包, 基礎知識]

### 白話解釋
你可以把網路封包想像成「網路世界的信封」。當你在網路上傳送資料時（比如瀏覽網頁、傳訊息），資料會被切割成很多小塊，每一塊就像一封信，裡面有收件地址（目的 IP）、寄件地址（來源 IP），以及信件內容（資料本身）。這些「信封」就是封包。

### PCAP 是什麼？
PCAP（Packet Capture）就是把這些「信封」全部記錄下來的檔案格式。就像在郵局裝一台影印機，把每一封經過的信都影印一份留存。資安人員可以事後分析這些封包，找出可疑的通訊行為。

## CNN 異常偵測模型
[tags: cnn, 模型, 異常偵測, autoencoder, 自編碼器, 機器學習, 深度學習, 重建誤差]

### VNAAP 的 CNN 模型是什麼？
VNAAP 使用一種叫做「卷積自編碼器（CNN Autoencoder）」的深度學習模型來偵測異常流量。這個模型先學習「正常流量長什麼樣子」，然後遇到新的流量時，如果模型無法很好地「重現」它（重建誤差高），就代表這個流量可能是異常的。

### 什麼是重建誤差？
簡單來說，模型會試著把每個封包「壓縮再還原」。如果還原後跟原本差很多（重建誤差高），代表這個封包跟模型學過的「正常模式」不一樣，很可能是攻擊流量。

### 閾值（Threshold）是什麼？
閾值就是「分數線」。重建誤差超過這條線的封包就會被標記為「異常」。閾值太低會誤報太多，太高會漏掉真正的攻擊。VNAAP 提供了閾值調校工具來找到最佳的平衡點。

## Grad-CAM 熱力圖
[tags: gradcam, grad-cam, 熱力圖, 視覺化, 可解釋, xai, 哪些byte觸發]

### 什麼是 Grad-CAM？
Grad-CAM 是一種「讓 AI 解釋自己」的技術。當 CNN 模型判定一個封包是異常的，Grad-CAM 可以產生一張「熱力圖」，用顏色標示出封包中**哪些位元組區域**是讓模型做出這個判斷的關鍵依據。紅色越深代表影響越大。

### 看熱力圖能知道什麼？
- 如果紅色集中在**封包標頭**區域：可能是 TCP/IP 標頭欄位異常（如異常的 Flag 組合）
- 如果紅色集中在**封包內容**區域：可能是 Payload 內容異常（如惡意指令）
- 可以幫助資安人員**快速定位**問題所在，不需要逐一比對整個封包

## VNAAP 平台 — 上傳 PCAP 檔案
[tags: 上傳, upload, pcap, 怎麼上傳, 操作教學, 使用教學]

### 如何上傳 PCAP 檔案進行分析？
1. 登入 VNAAP 平台
2. 進入左側選單的「**分析 Session**」頁面
3. 點擊右上角的「**新增分析**」按鈕
4. 選擇或拖曳你的 PCAP 檔案（支援 .pcap / .pcapng 格式）
5. 選擇要歸屬的專案（可選）
6. 點擊「**開始分析**」
7. 系統會自動進行封包解析、異常偵測、告警產生

### 注意事項
- 檔案大小上限為 500 MB
- 分析過程需要一些時間，大型 PCAP 可能需要幾分鐘
- 分析完成後會自動跳轉到結果頁面

## VNAAP 平台 — 查看分析結果
[tags: 分析結果, 結果, 告警, alert, 怎麼看結果, 操作教學]

### 如何查看分析結果？
1. 進入「**分析 Session**」頁面
2. 點擊已完成的 Session（狀態顯示為「完成」）
3. 你會看到以下資訊：
   - **摘要統計**：封包總數、告警數量、異常偵測率
   - **告警清單**：每個可疑行為的詳細資訊（攻擊類型、嚴重等級、來源/目的 IP、建議處置方式）
   - **CNN 異常偵測結果**：重建誤差分布圖、正常 vs 異常封包數量
   - **Grad-CAM 熱力圖**：可視化每個異常封包的觸發區域

## VNAAP 平台 — 產生 Grad-CAM 熱力圖
[tags: 產生gradcam, 熱力圖操作, 怎麼產生, 視覺化操作]

### 如何產生 Grad-CAM 熱力圖？
1. 進入一個已完成分析的 Session 詳情頁
2. 找到「**Grad-CAM**」區塊
3. 點擊「**產生熱力圖**」按鈕
4. 可設定：
   - **最大圖片數**：一次最多產生幾張（預設 20）
   - **只看異常**：只為被標記為異常的封包產生熱力圖
5. 產生完成後，點擊任一張縮圖即可放大檢視

## 什麼是 IDS / IPS？
[tags: ids, ips, 入侵偵測, 入侵防禦, 資安設備]

### IDS（入侵偵測系統）
IDS 就像大樓的監視器——它會**監看**所有進出的網路流量，發現可疑行為時發出警報，但不會主動阻擋。VNAAP 的角色就類似一個進階的 IDS。

### IPS（入侵防禦系統）
IPS 就像大樓的保全——它不只會監看，還會**主動阻擋**可疑的流量。比 IDS 更進一步，但也有誤擋正常流量的風險。

## 網路安全基本觀念
[tags: 網路安全, 基本觀念, 防護, 保護, 一般人, 個人安全]

### 一般人可以怎麼保護自己？
1. **密碼安全**：使用長度 12 字元以上的密碼，混合大小寫英文、數字、符號。不要在不同網站使用相同密碼，建議使用密碼管理器
2. **軟體更新**：作業系統、瀏覽器、App 有更新通知就趕快更新，很多更新都包含安全修補
3. **注意釣魚**：不要點擊可疑的連結或附件，尤其是要你「緊急」輸入帳號密碼的信件
4. **使用 HTTPS**：上網時注意網址列是否有🔒圖示，避免在不安全的網站輸入敏感資料
5. **公共 Wi-Fi**：在咖啡廳、機場等公共場所使用 Wi-Fi 時，建議開啟 VPN
6. **定期備份**：重要檔案遵循 3-2-1 原則（3 份備份、2 種媒體、1 份異地）
